description: Session-open ritual — rebuild the world from records, then brief the principal before touching anything.
---

Execute the boot ritual defined in `skills/boot/SKILL.md` (installed copy):

1. Read the installed charter (JARVIS.md).
2. Read the git timeline per repo (log/branch/status) — git before documents.
3. Read `.jarvis/LEDGER.md` and cross-check against git; note any drift.
4. Read `.jarvis/HANDOVER.md`; note the last-updated stamp.
5. Scan `.jarvis/MEMORY.md`; open memories relevant to today.
6. Brief the principal: last state, current state, proposed next first task,
   any drift found, open decisions. Then STOP and wait for direction —
   boot ends in DISCUSS mode, never in unrequested work.
