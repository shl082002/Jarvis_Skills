description: Grade the current work on the evidence ladder and close the gap to "verified" — honestly.
---

Apply `skills/verify-live/SKILL.md` to the work at hand:

1. List every claim currently being made about the work.
2. Grade each on the ladder: CLAIMED / COMPILED / TESTED / LIVE-VERIFIED /
   PRINCIPAL-VERIFIED. No inflation — name the rung actually earned.
3. For each claim below LIVE-VERIFIED: either drive the real system now and
   capture evidence (response bodies, screenshots, log lines), or state
   plainly what blocks verification.
4. Report: claims with rungs and evidence, failures with actual output quoted,
   and the exact manual test steps prepared for the principal (their manual
   pass — not machine verification — is the default final gate).
