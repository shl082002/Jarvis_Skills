Switch to BUILD mode per `skills/two-modes/SKILL.md` and execute under
`skills/build-discipline/SKILL.md`:

1. Confirm the plan is locked (ratification note / the principal's go-word).
   Open decisions are now yours to call — call them, log the calls.
2. Per slice: isolated worktree, `BRANCH_PREFIX<slice>` branch off the stack
   tip, minimal diff, verification gates before each commit, flag anything new.
3. Record: ledger entry at branch creation; deviations appended to the plan
   doc; STOP order on false premises (halt slice, file evidence, continue
   independent slices).
4. Wrap: dock deliberately, hand the principal exact manual test steps, update
   ledger/memory/handover. Machine verification only if they ask. Never push.
