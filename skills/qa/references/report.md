# QA report template

```
# QA — <slug>
Date · tier · mode (report-only | fix) · URL/port

## Claim
Falsifiable: what should be true.

## Evidence
- path / action
- result (status, quote, screenshot path)
- rung: CLAIMED | COMPILED | TESTED | LIVE-VERIFIED

## Findings
| Sev | Finding | Evidence | Status (open / fixed-this-mission) |
|-----|---------|----------|--------------------------------------|

## Not tested
Named gaps. Absence is not a pass.

## Blockers
Principal or env. Money leftovers.
```
