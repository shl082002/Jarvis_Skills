# Judgment library (kit asset)

Portable mental-model cards. **Not** the charter. Invoked only via the `teach`
command / `skills/judgment-library/`.

- Phase 1 (modules 1–9): tools — what and when
- Phase 2 (modules 10–14): lenses — why the same forces recur
- Router: [CONCEPT-INDEX.md](./CONCEPT-INDEX.md)

Cards may still use third-party examples. The teach loop **restates on the
current product**. One topic per invocation.

No PDFs in the kit. Source handbook may live at a project `./learning/` as well;
after install, `.jarvis/kit/assets/learning/` is the copy agents should open.
